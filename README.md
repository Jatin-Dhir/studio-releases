# Studio

The studio's work, in one place: every piece from brief to the client's yes, who is on what, checks, the calendar, chat, files, the money. Built by Jatin Dhir for Devs's Marketing Mind.

## Get it

**[Download Studio for Windows](https://github.com/Jatin-Dhir/studio-releases/releases/latest/download/Studio-Setup.exe)**

Run the installer. Studio opens in its own window and keeps its work in a folder of its own on that computer. It updates itself: each new version is offered inside Studio within a quarter of an hour, or put in place when Studio is next opened.

Windows may say the publisher is unknown the first time. Choose *More info*, then *Run anyway*.

On a phone, a tablet or a Mac, Studio is the same app in the browser: open the address of the computer that runs it, then *Add to Home Screen* (iPhone), *Add to Home screen* (Android) or *Add to Dock* (Mac).

## What is here

Every version's installer, its block map and `latest.yml` sit under [Releases](https://github.com/Jatin-Dhir/studio-releases/releases). Installed copies read `latest.yml` from the newest release and fetch the installer whose checksum it names; nothing is trusted that does not match.
